# Tagalong v0 (artifact for the judge)

Tagalong is a free, installable, offline web app (PWA). No account, no server, zero runtime dependencies.
The three attached images are real screenshots of this version: (1) phone 390 px: first run, plan tab, ideas
tab, money tab, passport in dark mode; (2) desktop 1280 px first run; (3) desktop 1280 px passport.
The sample trip in the screenshots is demo data that ships with the app (`?demo=1`).

## What this version does

Planning
- Trips with one or more stops and a day-by-day itinerary. Each day is loose (Morning / Afternoon / Evening)
  or on the clock, chosen per day.
- Clock days show the free gaps between events; one tap fills a gap.
- Drag an event to another day or block, or move it from the edit sheet (keyboard and touch).
- Ideas shortlist with votes; the most wanted idea sorts first; one tap schedules it onto a day.
- Every delete has Undo.
- Invite link carries the whole trip (no sign-in). Opening someone else's link merges: newest edit of each
  item wins, votes add up. This is link sync, not live sync.
- Calendar export (.ics). Map link per event.

Money
- Even split, split by shares, or itemised with tax and tip spread in proportion.
- Paste receipt text and it becomes line items (no camera scan).
- Any currency per expense with the rate actually paid.
- Balances per person, and the fewest transfers that settle everyone, each with "Mark paid".
- Integer minor units throughout, so parts always add up to the bill.

Passport (travel history)
- Finished trips become a history by themselves: countries, cities, trips, days away, return visits, flights,
  road trips, companions, country stamps, a world map (been there / planned), a trip log.
- "Log a past trip" for trips taken before installing. One cover photo per trip.
- Kept in the browser's storage only; backup and restore as one JSON file.

## Known weaknesses of this version (honest)

- No live sync between phones (link merge only). No camera receipt scan. No saved-place collections.
  No roles (admin/member). No native App Store build.
- Desktop first run: the right half of the hero is empty.
- Phone passport: seven figures in three columns feel cramped and the world map is small.
- Phone plan tab: the day strip is cut at the right edge with no hint that it scrolls.

## Code-checked evidence (not for re-scoring)

- Unit tests 12/12: splits sum exactly to the bill, balances sum to zero, settle-up clears every balance,
  merge is commutative and keeps the newest edit, share link round-trips.
- Browser gates 9/9 on 8 viewports, light and dark: no console errors, no horizontal overflow 320 to 1440 px
  (113 checks), WCAG AA contrast (113), tap targets >= 44 px (43), no text under 12 px (113), offline start (7),
  end-to-end flow incl. share link opened in a clean profile (62), money rows add up to the total (12).
